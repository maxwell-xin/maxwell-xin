### AI Application Engineer | Flutter · Laravel · Kotlin | Agentic systems, MCP

I build things people actually use — Android apps in Kotlin, Flutter apps, Laravel backends on Linux boxes I set up myself.

Lately I've been building my own things with AI. [OOTD](https://ootd.maxcloudapps.com/) and [TailorTrip](https://tailortrip.maxcloudapps.com/) are on Google Play, both Gemini-powered. [RaveFarm](https://ravefarm.maxcloudapps.com/) is the one I'm most into — no data APIs at all, just an agent that goes and finds festivals on a schedule and writes them into my backend through an MCP server I built. The hard part isn't the agent, it's making sure it can't put garbage in the database.

I also build custom Claude Code agent skills that automate the boring parts — test generation, API diagrams, commit messages, project scaffolding.

Some of my work, like my LLM proxy and my agent skills, lives in private repos.
